# Style provenance
MLSys 2027's official CFP explicitly reuses the MLSys 2025 format:
https://mlsys.org/Conferences/2027/CallForResearchPapers
Official archive: https://media.mlsys.org/Conferences/MLSYS2025/mlsys2025style.zip

The archive could not be materialized in this execution environment. The style
source was retrieved through the GitHub connector from the public mirror:
https://github.com/OpenMachine-ai/transformer-tricks/blob/c3cec7e8076926acd2a31c2e5d7eadfd47489318/tex/mlsys2025.sty
Original source Git blob: 7a942961bb77039dfd3d18794034b3427802be2c.

The supplied file is a comment-condensed transcription of its active formatting
commands, including the geometry checks and review line ruler. It is NOT claimed
byte-identical to the official ZIP. Diagnostic messages and unused deprecated
commands were condensed. No margin/font/spacing settings were altered to fit
this manuscript. Before submission, replace mlsys2025.sty with the file from the
official archive and compile again. The build uses the review option, never an
old accepted-paper imprint. The bibliography uses plainnat, listing all authors.
